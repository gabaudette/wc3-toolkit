# Engineering Standards

AGE Studio standards define strong defaults without forcing one language, framework, operating system, or editor across every project.

The standards are grouped by concern:

- **AGE-WS** — whitespace and logical code organization
- **AGE-ERR** — error handling and observability
- **AGE-DES** — software design
- **AGE-QUAL** — compilers, linters, formatters, CI, and editor integration
- **AGE-TECH** — technology selection, portability, and open-source policy
- **AGE-TS** — TypeScript-specific conventions

## General philosophy

AGE favors explicit behavior, maintainable code, portable tooling, open technologies, and automated enforcement.

Standards should improve clarity and reliability. They should not create abstraction or process merely for its own sake.
