Guides/Abilities/Your first custom spell
Make something · abilities

A spell of your own.

Start with a familiar ability, make it yours, and give it to a unit. No scripts needed for this first one.

BeginnerTinkerbench + World EditorAbout 10 minutes
BEFORE YOU START

Open a test map in Tinkerbench. You’ll place and test the unit in the World Editor after saving your changes.

1Pick a base ability

In Abilities, find Holy Light (AHhb). Create a custom ability from it and name it Sunwell Touch. Keep its new raw code handy: scripts use this ID to find your spell.

FieldYour valueWhat changes
Text · NameSunwell TouchThe name in the editor
Stats · Cooldown8 / 7 / 6Seconds between casts
Stats · Mana Cost50 / 65 / 80Mana spent per level

2Meet the same spell in Lua

Later, you can read your custom ability from a trigger. Replace A000 with the raw code Tinkerbench assigned.

LuaJASS
spell.lua
-- Inside a spell-effect trigger action
local spellId = GetSpellAbilityId()
if spellId == FourCC("A000") then
    local caster = GetTriggerUnit()
    -- Your custom behavior starts here.
end
